This repository contains material developed in the context of the Basics of Image Processing.

The work explores fundamental concepts of image processing through a series of practical implementations, including image enhancement and contrast manipulation, Fourier transform analysis with magnitude and phase, two dimensional sampling and aliasing effects, frequency domain filtering and color processing, edge detection and contour extraction, interest point detection using the Harris corner detector, image splitting and merging operations, color quantification and content based image retrieval, and face recognition using the Eigenfaces method.

The repository is organized by topic, with each folder corresponding to a specific theme addressed, and contains code and notebooks illustrating the underlying methods and their applications.
